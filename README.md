# Files-V

Files-V - это утилита командной строки для работы с файлами, написанная на Golang.

## Функциональность

- Рекурсивный просмотр содержимого директорий (включая все вложенные папки и файлы)
- Автоматическое создание временной копии директории в `__fv__` перед обработкой
- Полное копирование всех файлов и директорий, включая скрытые файлы
- Шифрование содержимого скопированных файлов с использованием AES-256
- Расшифровка зашифрованных директорий с префиксом `__fv__`
- Возможность указать пароль шифрования/расшифровки через командную строку
- Запрос пароля шифрования в консоли, если он не указан явно
- ZIP-архивация директорий с последующим шифрованием архива (флаг `-z`/`--zip`)
- Автоматическое распознавание и распаковка зашифрованных ZIP-архивов (`.zip.efv`)
- [Будет дополнено] Поиск файлов
- [Будет дополнено] Обработка файлов

## Принцип работы

1. При запуске программы указывается директория для обработки
2. Пароль для шифрования/расшифровки можно указать через флаг `-p` или `--password`
3. Если пароль не указан, программа всегда запросит его интерактивно (ввод будет скрыт для безопасности)
4. Режим шифрования (по умолчанию):
   - **Обычный режим**:
     - Программа создает временную директорию `__fv__{имя_директории}`
     - Копирует абсолютно всё содержимое исходной директории во временную
     - Шифрует содержимое всех скопированных файлов
   - **Режим ZIP** (с флагом `-z` или `--zip`):
     - Программа создает ZIP-архив из указанной директории
     - Шифрует весь архив целиком и сохраняет с расширением `.zip.efv`
5. Режим расшифровки:
   - **Обычный режим** (директория с префиксом `__fv__` или флаг `-d`):
     - Программа создает директорию `d{имя_директории}` рядом с исходной
     - Копирует всё содержимое зашифрованной директории
     - Расшифровывает каждый файл
   - **Режим ZIP** (для файлов с расширением `.zip.efv`):
     - Программа расшифровывает файл архива
     - Распаковывает его содержимое в директорию с именем исходного архива (без `.zip.efv`)

## Шифрование и расшифровка

Для шифрования и расшифровки файлов используется алгоритм AES-256 с режимом шифрования CFB:
- Пароль шифрования можно указать через флаг `-p` или `--password` (если не указан, будет запрошен интерактивно)
- Для каждого файла генерируется уникальный вектор инициализации
- Шифрование выполняется после копирования файлов во временную директорию или создания ZIP-архива
- Расшифровка выполняется при указании флага `-d`, для директорий с префиксом `__fv__` или файлов с расширением `.zip.efv`
- **Важно**: Для расшифровки файлов необходимо использовать тот же пароль, которым они были зашифрованы

## Установка

```bash
go get github.com/yourusername/files-v
```

## Использование

```bash
# Просмотр указанной директории (обязательный аргумент)
files-v <путь_к_директории>

# Примеры шифрования
files-v /home/user/documents  # будет запрошен пароль шифрования
files-v /home/user/documents -p mykey123  # с указанием пароля
files-v .                    # создаст __fv__files-v внутри текущей директории

# ZIP-архивация и шифрование
files-v /home/user/documents -z  # создаст documents.zip.efv, будет запрошен пароль
files-v /home/user/documents -z -p mykey123  # с указанием пароля

# Режим расшифровки
files-v __fv__documents      # будет запрошен пароль расшифровки
files-v __fv__documents --password mykey123  # с указанием пароля
files-v documents -d         # будет запрошен пароль расшифровки
files-v documents -d -p mykey123  # расшифровка с указанным паролем

# Расшифровка и распаковка ZIP-архива
files-v /home/user/documents.zip.efv  # будет запрошен пароль, извлечет в директорию documents
files-v /home/user/documents.zip.efv -p mykey123  # с указанием пароля

# Использование флагов
files-v <путь_к_директории> --help
```

## Разработка

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/files-v.git
cd files-v

# Запуск приложения с указанием директории (обязательно)
go run ./cmd/files-v <путь_к_директории>

# Примеры
go run ./cmd/files-v .       # создаст __fv__files-v в текущей директории, запросит пароль
go run ./cmd/files-v /tmp    # создаст __fv__tmp рядом с /tmp, запросит пароль
go run ./cmd/files-v /tmp -p secret123  # шифрование с паролем "secret123"
go run ./cmd/files-v /tmp -z # создаст tmp.zip.efv с ZIP-архивом, запросит пароль

# Запуск в режиме расшифровки
go run ./cmd/files-v __fv__documents # расшифрует директорию, запросит пароль
go run ./cmd/files-v documents -d    # расшифрует директорию, запросит пароль
go run ./cmd/files-v documents.zip.efv # расшифрует и распакует ZIP-архив, запросит пароль

# Сборка исполняемого файла
go build -o files-v ./cmd/files-v
```
